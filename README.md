# Individual-Based Model (IBM)
This IBM simulates the population dynamics and genetics of a generic invasive 
species across space. The model is used to investigate how genetic load influences 
invasion success, spread rate, and population establishment.

#Steps to run the model

1. To simulate a founder event, locate the "R_allee"" folder and follow the steps 
in the script *run_allee.R*.


2. To simulate invasion dynamics across 2 to n patches, locate the "R"" folder and 
run the script *run_file.R*.


3. In each folder, the *parameter_* script contains the parameter values, which 
can be modified as needed.


4. Simulation results can be saved to the "output"" folder. Use the script 
*analysis_plot.R* to analyse the results and generate figures/plots._
