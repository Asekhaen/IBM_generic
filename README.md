# Individual-Based Model (IBM)
This IBM simulates the population dynamics and genetics of a generic invasive 
species across space. The model is used to investigate how genetic load influen-
ces invasion success, spread rate, and population establishment.

#Steps to run the model

1. To simulate a founder event, locate the *R_allee* folder and follow the 
steps in the script  *run_allee.R*

2. To simulate a 2 to *n* patch, invasion dyanmics, locate the *R* folder and 
run the script *run_file.R*

3. In each folder, the *parameter_* R script contains the parameter values that 
can be set as desired

4. The results of the simulations can be saved to the *output* folder and script
 *analysis_plot.R* to analyse and generate figures/plots
